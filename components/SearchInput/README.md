# SearchInput

Busca com lupa, botão de limpar e estado de carregamento; usada para localizar endereço, bairro ou empreendimento.

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `size` | `"sm" ∣ "default" ∣ "lg"` | não | Size scale for search input height and padding |
| `onClear` | `() => void` | não | Callback fired when the clear (X) button is clicked |
| `isLoading` | `boolean` | não | Shows a spinning loading indicator in place of the magnifying glass |

Código-fonte: `uxpilot/src/components/ui/SearchInput.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.SearchInput`.
