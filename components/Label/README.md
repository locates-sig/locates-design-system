# Label

Rótulo de campo em cinco tamanhos (micro 10px a lg), com asterisco de obrigatório.

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `size` | `"micro" ∣ "xs" ∣ "sm" ∣ "default" ∣ "lg"` | não | Size scale ranging from micro uppercase labels to standard text |
| `required` | `boolean` | não | Renders a red required asterisk next to label text |

Código-fonte: `uxpilot/src/components/ui/Label.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.Label`.
