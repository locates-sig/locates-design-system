# FloatingInput

Campo sem caixa com label flutuante e trilho de 2px que fica roxo no foco; exclusivo dos fluxos de autenticação.

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `label` | `string` | sim | Field label that floats above the input when focused or populated |
| `error` | `string` | não | Error message displayed below the 2px underline track |
| `rightElement` | `React.ReactNode` | não | Optional action or icon element rendered on the right side |

Código-fonte: `uxpilot/src/components/ui/FloatingInput.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.FloatingInput`.
