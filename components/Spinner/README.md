# Spinner

Indicador de carregamento circular em quatro cores e cinco tamanhos, com rótulo acessível (padrão "Carregando...").

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `variant` | `"primary" ∣ "white" ∣ "muted" ∣ "secondary"` | não | Visual color theme variant |
| `size` | `"xs" ∣ "sm" ∣ "default" ∣ "lg" ∣ "xl"` | não | Size scale |
| `label` | `string` | não | Screen reader label for accessibility |

Código-fonte: `uxpilot/src/components/ui/Spinner.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.Spinner`.
