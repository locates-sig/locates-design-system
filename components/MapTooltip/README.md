# MapTooltip

Rótulo escuro de hover sobre feições do mapa, com sublinha e ponto de cor opcionais.

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `label` | `React.ReactNode` | não | Primary label or title displayed inside the tooltip |
| `sublabel` | `React.ReactNode` | não | Optional sublabel or value text |
| `tipPosition` | `"top" ∣ "bottom" ∣ "left" ∣ "right" ∣ "none"` | não | Pointer arrow tip position when attached to map elements |
| `dotColor` | `string` | não | Optional status or indicator dot color |

Código-fonte: `uxpilot/src/components/ui/MapTooltip.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.MapTooltip`.
