# Skeleton

Bloco pulsante que ocupa o lugar do conteúdo enquanto os dados carregam.

| Prop | Tipo | Obrigatória | Descrição |
| --- | --- | --- | --- |
| `variant` | `"default" ∣ "subtle" ∣ "circle" ∣ "card" ∣ "text"` | não | Visual fill and shape preset variant |
| `width` | `string ∣ number` | não | Custom inline width (e.g. 100, "100%", "20rem") |
| `height` | `string ∣ number` | não | Custom inline height (e.g. 40, "2.5rem") |

Código-fonte: `uxpilot/src/components/ui/Skeleton.tsx` (gerado no UX Pilot, design system "Locates"). Exportado como `LocatesApp.Skeleton`.
